# Chrome 应用商店填写内容（Arc Cmdbar）

上传：`npm run zip` 生成 `arc-cmdbar.zip`（已去掉 manifest 的 `key`）。

## 商店信息

- 名称：Arc Cmdbar
- 简短说明（manifest 的 description）：Arc 风格的命令栏：一个搜索框搜标签页、最近关闭、书签、历史记录和常用命令。
- 类别：工具（Tools）
- 图标：`icons/icon-128.png`
- 截图：至少 1 张，1280×800 或 640×400（需要自己截，弹出框宽 640px，可在一个 1280×800 的画面里居中）

## 隐私

**单一用途**：在一个搜索框里查找并切换到已打开的标签页、最近关闭的标签页、书签和历史记录，并执行常用的标签页命令。

**权限说明**

| 权限 | 用途 |
|---|---|
| tabs | 列出所有窗口里打开的标签页供搜索，并执行切换、关闭、固定、静音、移动等标签页命令。 |
| sessions | 列出并恢复最近关闭的标签页和窗口。 |
| bookmarks | 搜索书签并打开。 |
| history | 搜索浏览历史并打开。 |
| favicon | 在结果列表里显示网站图标。 |
| storage | 在 `chrome.storage.session` 里记住固定标签页被固定时的网址，用于「重置标签页」；浏览器退出即清空。 |
| search | 输入不是网址时，用用户设置的默认搜索引擎搜索。 |
| clipboardWrite | 「复制当前网址」「复制为 Markdown 链接」命令写入剪贴板。 |

没有网站权限（host permissions），没有内容脚本，不使用远程代码。

**数据使用**：不收集、不传输任何用户数据。所有数据只在弹出框打开时从 Chrome 本地读取，不上传、不出售、不用于与单一用途无关的目的。

## 上架后

商店分配 id 后，把它和 Pinline 的 id 一起改进代码（见 README「已知限制」），再把后台「软件包 → 公钥」填回 manifest 的 `key`，本地开发版 id 就和商店版一致。
